# DNS Changer

A fast, lightweight web tool to switch Windows DNS via auto-generated `.BAT` scripts.

## Features

* **One-click BAT export**: Easily switch DNS or reset to DHCP.
* **IPv4 & IPv6**: Full support for both IP versions.
* **Dark Mode**: Auto-adapts to system theme.
* **Minimalist UI**: Clean, responsive, and easy to use.

## Quick Start

1. Open `index.html` in your browser.
2. Select a DNS provider.
3. Click **Download .BAT**.
4. Run the downloaded file as **Administrator**.
